    华天科技（002185）¶

    【未来成长空间评级】极高 1. 政策层面→半导体国产替代为国家级长期主线，先进封装是国内芯片绕开先进制程限制的核心路径，监管层2026年持续鼓励半导体产业并购整合，公司29.96亿元收购功率半导体标的华羿微电符合政策导向，补全功率器件设计-封测-品牌全链条，打造第二增长曲线。 2. 业绩弹性→华羿微电聚焦高性能功率器件，下游覆盖新能源汽车、光伏储能等高景气领域，2025年功率半导体业务营收增速超40%，并表后预计年增厚净利润3.5-4.5亿元，公司原有先进封装业务受益于AI芯片、存储芯片封测需求爆发，2026年封测订单已排至Q4，全年净利润增速有望达65%-80%。 3. 资金强度→7月7日当日主力资金午盘即净流入28.85亿元，居两市首位，龙虎榜显示3家机构席位合计净买入12.7亿元，北向资金净买入4.2亿元，资金认可度极高，近3日累计主力净流入超42亿元。 4. 行业地位→公司为国内前三的集成电路封测龙头，先进封装产能占比达42%，存储芯片封测、AI芯片Chiplet封装技术国内领先，已进入华为海思、长鑫存储、英伟达供应链，客户壁垒深厚。 5. 政策持续性→半导体国产替代政策扶持周期预计至少持续5-10年，先进封装作为国家大基金三期重点投资方向，公司后续有望获得大基金增资、税收减免等政策支持，长期成长确定性强。

    【利空风险分析】 1. 并购整合风险→收购华羿微电为关联交易，标的业绩承诺完成率存在不确定性，若后续功率半导体行业价格战加剧，标的毛利率可能从当前38%下滑至30%以下，业绩贡献不及预期。 2. 行业竞争风险→国内封测厂商长电科技、通富微电均在大幅扩产先进封装产能，2026年行业先进封装产能增速达35%，或存在产能过剩、价格战导致公司封装单价下滑的风险。 3. 下游需求波动风险→消费电子需求复苏不及预期，若AI芯片厂商资本开支下滑，可能导致公司高端封测订单增速低于预期。 4. 估值风险→当前公司动态市盈率达48倍，高于封测行业32倍的平均估值，短期股价涨幅较大，存在情绪退潮后的估值回调风险。

    TCL中环（002129）¶

    【未来成长空间评级】极高 1. 政策层面→光伏“反内卷”、BC电池技术迭代为2026年光伏行业核心主线，7月最新发布的光伏三项强制性新国标推动行业出清落后产能，公司作为BC电池技术龙头直接受益于行业技术升级和格局优化。 2. 产能落地→公司拟投资26亿元升级改造20GW BC电池、25GW BC组件产能，预计2026年Q4投产，BC电池转换效率达26.8%，较PERC电池高3pct，单瓦盈利较TOPCon电池高0.15-0.2元，达产后预计年增厚净利润28-32亿元。 3. 业务协同→公司同时具备210mm大尺寸光伏硅片、12英寸半导体硅片产能，半导体硅片已进入中芯国际、华虹半导体供应链，2026年半导体硅片业务营收占比将提升至22%，第二增长曲线清晰。 4. 资金强度→7月7日当日主力资金净流入6.54亿元，居光伏板块首位，近5日累计主力净流入12.3亿元，机构资金持续加仓，当日封单金额达7.8亿元，封板强度较高。 5. 业绩弹性→2026年Q2光伏硅片价格企稳回升，单瓦盈利修复至0.08元，BC电池量产后公司整体毛利率将从当前16%提升至23%，全年净利润有望达85-95亿元，同比增速超120%。

    【利空风险分析】 1. 技术迭代风险→光伏行业技术迭代速度快，若HJT、钙钛矿电池技术突破速度超预期，BC电池可能面临技术路线被替代的风险，公司产能投入或面临减值。 2. 产能过剩风险→2026年光伏硅片行业总产能超800GW，而全球需求仅550GW，硅片环节竞争依然激烈，若后续硅片价格再度下跌，公司传统硅片业务盈利可能再次承压。 3. 政策变动风险→美国若进一步扩大对中国光伏产品的进口关税限制，公司海外组件出口业务可能受到冲击。 4. 项目进度风险→BC电池产能改造可能受设备交付、工艺调试等因素影响，存在投产进度慢于预期的风险。

    万通发展（600246）¶

    【未来成长空间评级】极高 1. 技术壁垒→公司控股70%的子公司数渡科技PCIe5.0交换芯片已实现量产，单颗均价3000元，毛利率达59.8%，是国内少数能量产高端PCIe交换芯片的厂商，技术壁垒极高，打破海外厂商垄断。 2. 业绩弹性→中性情景下（联通50万颗、华为30万颗订单落地），2026年数渡科技可贡献权益净利润9.06亿元，而公司2025年全年净利润仅0.87亿元，业绩增速超900%；保守情景下也可贡献权益净利润4.67亿元，业绩弹性极大。 3. 赛道空间→PCIe5.0交换芯片是AI算力集群、服务器、数据中心的核心芯片，国内市场规模2026年达180亿元，海外厂商博通、Microchip市占率超95%，国产替代空间广阔。 4. 资金强度→7月7日当日主力资金净流入5.11亿元，近3日累计净流入11.7亿元，2连板过程中龙虎榜显示游资和机构合力买入，资金承接力度强。 5. 转型逻辑→公司原有地产业务逐步收缩，全面转型AI算力芯片赛道，后续不排除进一步收购芯片资产的可能，转型成长逻辑顺畅。
